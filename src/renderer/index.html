点击后打开微软登录窗口，在窗口里登录即可。不需要设备码，也不需要配置 Azure。密码只输入在微软页面上。

离线模式

离线账户仅用于局域网/社团内服，不能进入正版服务器。用户名 3-16 位英文、数字或下划线。

离线 UUID 由用户名按 Minecraft 规则生成，同一用户名在不同电脑上保持一致。

第三方外置登录（authlib-injector）

支持任意 HTTPS Yggdrasil / authlib-injector 验证服务器，例如 LittleSkin。密码只发送给该验证服务器，不保存。

把第三方网站的一键登录按钮拖到这里，自动填入验证服务器地址

外置登录不能登录正版服务器。请确认验证服务器可访问，并只在你信任的服务器输入密码。

关于 QUTC Launcher

QUTC Minecraft Club 内部启动器。纯本地运行，无遥测、无广告、无第三方账号上传。

  • 渲染进程无 Node 权限，所有操作走白名单 IPC。
  • 原版与资源全部校验 Mojang 官方 SHA-1。
  • Forge/NeoForge 官方安装器需显式同意，并优先校验 SHA-1。
  • 版本压缩包解压前检查路径穿越、符号链接与压缩炸弹。
